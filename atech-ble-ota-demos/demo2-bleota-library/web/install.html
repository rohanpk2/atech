One-time USB install of the Demo 2 baseline

Checking

Writes the bootloader, partition table, OTA selector and the Demo 2 base firmware over USB with ESP Web Tools (Web Serial). This works in desktop Chrome and Edge only. Safari and Firefox have no Web Serial; on those browsers use the PlatformIO command below instead. After this one-time install, every later update travels over Bluetooth or Wi-Fi.

  1. The builder backend serves the four image parts from the Demo 2 base build.
  2. Connect the ESP32-S3 DevKitC-1 with a data-capable USB-C cable. If no serial port shows up in the picker, hold BOOT, tap RST, release BOOT, then try again.
  3. Click the install button, pick the board's serial port, and allow the full erase when asked. The install replaces everything on the flash, including NVS, so the board generates new Wi-Fi OTA credentials.
  4. When it finishes, open Logs & Console in the same dialog and press RST. The boot log prints the device ID, pairing code, Wi-Fi hotspot name, WPA2 password and portal token. Record them now.
  5. Return to the dashboard and connect over Bluetooth. The board advertises as Atech-Library-OTA-<pairing code>.

Checking whether the base image parts are available.

This browser has no Web Serial. Use desktop Chrome or Edge, or run the PlatformIO command below. Web Serial needs a secure page: HTTPS or http://localhost.

Command-line equivalent (any browser, any OS):

cd demo2-bleota-library
pio run -e base -t upload
pio device monitor -b 115200
