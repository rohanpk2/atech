    Board hotspot: set up Wi-Fi or upload by hand
    
        Open 192.168.4.1
      
    
      
    This dashboard does not fetch or upload to the device over the hotspot. Disconnect any active Bluetooth session, join the board's hotspot, and finish on its local page. Use this once to join the board to your home Wi-Fi; after that, Deploy uses Wi-Fi directly.
    
      
      
        
    1. With the firmware running, hold the physical BOOT button for about 3 seconds, then release it. Do not press RST.
      2. 
        
    2. Join Atech-OTA-D1-<suffix> in Wi-Fi settings. The suffix is the board's pairing code; the WPA2 password and the OTA authorization code come from the 115200-baud serial output printed at boot (the USB installer console shows it). Stay connected if the phone warns that the network has no Internet.
      3. 
        
    3. Open http://192.168.4.1 in Safari or Chrome and enter the OTA authorization code.
      4. 
        
    4. Home Wi-Fi: tap Scan, choose your 2.4 GHz network, enter its password and tap Join this network. The page reports the board's new IP address. Back here, click Find devices and pair with the same code.
      5. 
        
    5. Manual upload: download the firmware above, select that application firmware.bin on the board's page (not a bootloader, partitions, or merged image), then tap Deploy Firmware. Wait for verified success and reboot.
